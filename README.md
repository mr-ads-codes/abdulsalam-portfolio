# Abdul Salam — Professional Portfolio

A fast, responsive personal portfolio for Abdul Salam, presenting experience across project management, public-sector operations, international e-commerce, data, and digital products.

## Highlights

- Responsive one-page design with accessible navigation
- Optimized embedded WebP portrait and lightweight static assets
- Featured work covering FlatLedger, VYLMORA, IRFAN Tiles Zone, and Amazon operations
- Search and social metadata, JSON-LD, sitemap, and robots configuration
- GitHub Pages compatible with no build step

## Local preview

Serve the repository root with any static HTTP server, then open `index.html` through that server.

## Deployment

The production site is published through GitHub Pages from the repository's default branch.
